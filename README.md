## ◈ Overview

**Aurelius** is a personal portfolio and creative engineering platform built from the ground up to challenge conventional developer websites. Rather than presenting standard SaaS cards or cookie-cutter templates, the interface is styled as a **classified interactive archive** and **tactical HUD terminal**, drawing aesthetic inspiration from:

* **Resident Evil 4 Remake & Tactical Menus** — Inventory grids, ECG phosphor monitoring, biohazard telemetry, and classified dossier modals.
* **Atmospheric Horror & Cinematic Storytelling** — Layered volumetric mist, distressed film grain, organic vignettes, and dark monochrome palettes.
* **Minimalist Luxury Editorial Design** — High-contrast typography hierarchy, asymmetric editorial grids, and gold/crimson/sage accent accents.
* **Modern Creative Frontend Engineering** — Hardware-accelerated transitions, interactive custom cursors, real-time GitHub telemetry, and responsive glassmorphism.

### 1. Hero & Atmospheric Background Engine
- Multi-layered visual stack featuring a symmetrical ruins backdrop, multi-band volumetric mist gradients, radial vignette masking, and a localized typography scrim.
- Custom floating **Limelight Navigation Capsule** with active scroll spy, backdrop-blur isolation, and spring transitions.
- Custom **Crosshair Cursor System** tracking user input with physics-based spring smoothing and interactive state awareness.

### 2. Introduction Dossier & Biometric Scanner
- Center-outward **bubble unfolding reveal animation** built with weighted cubic-bezier easing curves.
- Multi-layer **Profile Viewport** featuring a continuous phosphor radar sweep, tactical reticle target, dynamic HUD corner brackets, and scanline shaders.
- Expandable **Technical Dossier Modal (`AboutModal.tsx`)** containing career history, design philosophy, educational credentials, and capability breakdowns.

### 3. "Tools of the Trade" // Tactical Inventory Grid
- Classified inventory system grouping technologies into structured slots with sequential LED capacity-charging meters.
- **Real-Time ECG Heart-Rate Monitor**: An HTML5 Canvas phosphor wave simulation running on a custom animation loop with natural Heart Rate Variability (HRV), baseline respiratory wander, random micro-jitter noise, and electrical static artifacts.

### 4. Work Library & Category Router
- Four-quadrant archive selector dividing creative output into **Graphic Design**, **Video Edits**, **UI/UX Design**, and **Code Projects**.
- Dynamic accent glows, corner bracket markers, and seamless smooth-scroll routing with navbar compensation.

### 5. Built From Scratch // Showcase Hub
- Comprehensive interactive showcase utilizing expandable modal cards with custom aspect-ratio handling (4:3 previews / 16:9 landscape technical dossiers).
- Full technical breakdowns, art direction rationale, collaborator attributions, live demo links, and GitHub repository references.

### 6. Live Contribution Telemetry
- Direct integration with the **GitHub Contributions API** displaying 52 weeks of real-world activity for `LuvyaNishad`.
- Fixed-coordinate floating tooltips, interactive hover-scramble cipher effects, mechanical counter tickers, and graceful offline fallback handling.

### 7. Communication Desk & Social Matrix
- Glassmorphic inquiry form with client-side verification, bot-deflection honeypot fields, and direct mailto fallback dispatchers.
- Social links rendered with custom brand colors, border highlights, and ambient glow on hover.

### Design Principles
1. **Atmosphere Over Decoration** — Every grain overlay, vignette, and blur filter serves to deepen immersion without causing visual clutter.
2. **Tactile Interaction** — Micro-animations, button light-beams, corner highlights, and scrambles acknowledge user focus.
3. **Resilient Architecture** — Zero monolithic code files; fully separated UI primitives, modular data layers, and accessible keyboard-navigable components.
