# Aurelius Portfolio

A cinematic Resident Evil-inspired portfolio website built with Next.js, Tailwind CSS, and Framer Motion.

## Tech Stack

* Next.js
* TypeScript
* Tailwind CSS
* Framer Motion
* Lenis

## Features

* Cinematic hero section
* Looping atmospheric video backgrounds
* Floating glassmorphism navbar
* Inventory-inspired tools section
* Tactical UI inspired layouts
* Responsive cinematic composition
* Atmospheric overlays and animations

## Getting Started

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Open:

```txt
http://localhost:3000
```

## Project Structure
